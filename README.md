# Agaetis Homebrew tap

Command-line tools published by [Agaetis](https://www.agaetis.fr), installable with [Homebrew](https://brew.sh) on macOS and Linux.

## Install

```sh
brew tap agaetis-it/tap
brew install <tool>
```

Or in one line: `brew install agaetis-it/tap/<tool>`.

## Tools

| Tool | Description | Project |
| --- | --- | --- |
| `takecare` | CLI of TakeCare Agents | [Agaetis-IT/takecare-agents](https://github.com/Agaetis-IT/takecare-agents) |

## How this tap is maintained

Casks in `Casks/` are generated by each project's release pipeline. Please do not edit them by hand: open an issue or a pull request on the tool's own repository instead.

Binaries are signed. Each project's documentation explains how to verify them.
